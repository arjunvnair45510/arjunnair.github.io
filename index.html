About

Physics, math, and the math that connects them

I'm a rising junior at Redmond High School focused on physics, mathematics, and signal processing. My work traces one idea — that decomposing a signal into its frequency components reveals what a raw time-series can't — across acoustics, computer vision, audio forensics, and seismology.

This started with a question about my own electric guitar build: why does it resonate the way it does? That question turned into a research throughline connecting a Celusion Technologies internship, independent research, and a Research mentorship.

Research

Projects, by signal domain

Each project applies the same core method — FFT / spectral analysis — to a different physical signal.

OPTICAL — IMAGE

Document Tamper Detection via 2D FFT

Detecting spatial-frequency artifacts left behind by copy-paste and re-compression tampering in scanned ID documents, built during a fraud-detection internship at Celusion Technologies.

In progress Python · NumPy · OpenCV
ACOUSTIC — VOICE

Spectral Features for Audio Deepfake Detection

Investigating which interpretable frequency-domain features best distinguish synthetic from genuine speech, using the ASVspoof dataset — an alternative to black-box detection models.

In progress Python · librosa · scikit-learn
MECHANICAL — VIBRATION

Guitar Resonance & Fourier Analysis

Measuring the resonant frequencies of a hand-built electric guitar using phone accelerometer and microphone data, comparing measured harmonics against theoretical string physics.

Complete Python · NumPy · SciPy FFT
SEISMIC — GROUND MOTION

Low-Cost Seismic Precursor Detection

A Research project testing whether frequency-domain signatures in low-cost accelerometer data can flag slope-instability precursors — motivated by the 2014 Oso landslide in Washington State.

Research Arduino · Python · FFT
